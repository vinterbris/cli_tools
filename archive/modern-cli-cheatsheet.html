Modern CLI Tools — Cheatsheet

Rule: new names for new tools; core commands keep core behaviour. Never alias grep/find to an incompatible tool.

rg — grep -r

rg patternrecursive search
rg -i / -wno-case / whole word
rg -F 'lit.str'fixed string
rg -l patfilenames only
rg -tpy patonly .py (-Tpy = excl.)
rg -g '*.conf' pglob filter
rg -C3 pat3 lines context
rg -uu patignore .gitignore+hidden
rg --fileslist searchable files
ugrep (ug) = grep-flag-compatible alternative.

fd — find

fd patternregex on filename
fd -e mdby extension
fd -tf / -tdfiles / dirs
fd -H / -Ihidden / ignore .gitignore
fd -g '*.tar.gz'glob mode
fd -d 2 patmax depth
fd . dir -x cmdexec per result
fd -0 | xargs -0null-safe pipe

fzf — interactive filter

Ctrl-Rfuzzy history
Ctrl-Tinsert file path
Alt-Ccd into picked dir
**<Tab>fuzzy path completion
cmd | fzf -mmulti-select (Tab)
--preview '…{}'preview pane
In-picker: Ctrl-J/K move · Tab mark · Ctrl-/ toggle preview

bat — cat (reading)

bat file.pyhighlight + numbers
bat -p fileplain, copy-safe
bat -A fileshow hidden chars
bat -r 20:40 fline range
bat -l json < fforce language
bat --diff fonly git-changed lines
Pipe-safe: acts as cat when not a TTY.

eza — ls

eza -lh --gitlong + git status
--icons=autoNerd Font icons
eza -lalong + hidden
eza --tree -L2replaces tree
--sort=size -rlargest first
--sort=modified -rnewest first
--total-sizereal dir sizes (slow)
exa is dead — use eza.

zoxide — cd

btop — top / htop

Esc menu · f filter · t tree view · +/− expand

gdu — ncdu

gdu -n /varnon-interactive

duf — df (NOT du)

--hide-fs tmpfshide noise
duf --sort sizesort

dust — du (non-interactive)

procs — ps aux | grep

hyperfine — time

-L n 1,4,8 'mk -j{n}'parameter sweep

delta — git pager

sd — sed s///

sd -s 'a.b' 'x' fliteral, no regex
fd -e md -x sd a bbulk across files
Substitution only — sed still owns the rest.

microuse it; nano = fallback
dust ≠ ncdugdu is the ncdu swap
duf ≠ duduf replaces df
fishnon-POSIX → use zsh
oh-my-zshheavy → 2 source lines
ugreppick over rg for grep flags

Install priority

1. zsh + 2 plugins · rg · fzf · fd
2. zoxide · bat · eza · delta · starship
3. btop · gdu · duf · procs · atuin · tldr · lazygit
4. yazi · xh · dust · sd · micro · hyperfine
Additive tools (fzf, zoxide, atuin, delta, btop, hyperfine, lazygit) have no coreutils equivalent — nothing to un-learn. Insurance for future remote work: keep grep -rn, find -name -type, du -sh, ps aux.

Combos worth memorizing

rg -l pat | xargs sd a b
bulk edit every match
fd -tf | fzf --preview 'bat {}'
pick a file visually
git branch | fzf | xargs git switch
fuzzy branch switch
curl -s $U | jq -r '.data[].id'
extract IDs from an API
rg --files | rg conf
find by path fragment
fd -e log -x gzip
batch-process matches

1. fzf --bash/--zsh

zsh on WSL

apt install zshinstall
chsh -s $(which zsh)default shell
wsl --shutdownPowerShell, to apply
wsl.exe ~ -e zshTerminal profile fallback
Skip oh-my-zsh: 2 source lines (autosuggestions + syntax-highlighting) replace it.

WSL gotchas

/mnt/c is slow — keep repos in ~/, never scan it with rg/fd/gdu
Nerd Font is set in the Windows Terminal profile, not in WSL
Slow tab-completion → appendWindowsPath=false in /etc/wsl.conf
Any /etc/wsl.conf change needs wsl --shutdown
